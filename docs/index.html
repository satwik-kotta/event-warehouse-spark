Event Warehouse

A Spark pipeline that turns 13 GB of nested JSON match events into a tested star schema. This page is the report of the latest full run: what was loaded, what was held back, and how much faster the result is to query.

Pipeline

Each stage reads only the output of the one before it, so the raw JSON is parsed exactly once.

What the checks found

Error-level checks stop the run. Warnings mean the source disagrees with itself: the rows are set aside and reported rather than loaded silently.
